# Faceless YouTube Channel

Production docs for a faceless, narrator-led explainer channel modeled on the hook and
storytelling patterns of SmarterEveryDay, The School of Life, MinutePhysics, SciShow,
Veritasium, and Kurzgesagt.

- [`docs/channel-analysis.md`](docs/channel-analysis.md) — hook mechanics, narrative
  structure, and visual language for each reference channel, plus the cross-channel hook
  formula distilled from all six.
- [`docs/script-doorway-effect.md`](docs/script-doorway-effect.md) — a full 5-minute,
  block-by-block script ("The Doorway Effect — Why You Forget Why You Walked Into a
  Room") written to that formula, ready for animated-explainer production (30 × 10s
  blocks, 16:9, 1080p).

## Video production status

The script is production-ready, but rendering it as video was not completed in this pass:
Seedance 2.0 at 1080p costs ~90 credits per 10-second clip, and a 5-minute video (30
blocks) needs roughly 2,700+ credits for visuals alone, against a workspace balance of
110 credits at the time of writing. See the script doc for the shot-by-shot breakdown
needed to render once credits are available.
